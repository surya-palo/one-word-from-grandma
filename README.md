## The word

**Witchcraft**

The single word Grandma would text about AI. She has heard "robot" and
"computer" all her life — those are not the joke. A box that answers back
in full sentences can only be one thing in her world: witchcraft. Warm, a
little baffled, and funny with no caption needed.

## How to run

```sh
python3 main.py
```

Writes exactly one word to `/output/entry.txt` (override with the
`OUTPUT_PATH` environment variable for local testing). Python standard
library only, deterministic — every run produces byte-identical output.
